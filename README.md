# FindSpot - Android Application

FindSpot adalah aplikasi berbasis Android yang dirancang untuk membantu pengguna menemukan rekomendasi tempat nongkrong, cafe, atau tempat belajar/bekerja berdasarkan lokasi, *budget*, dan suasana yang diinginkan.

---

##  Fitur Utama
* **Autentikasi Pengguna**: Registrasi akun dan Login menggunakan *Firebase Authentication*.
* **Pencarian Berdasarkan Preferensi**: Input *budget* per orang dan pemilihan lokasi yang tersedia.
* **Filter Suasana (Atmosphere)**: Menyaring tempat berdasarkan suasana seperti *Outdoor* atau *Quiet*.
* **Daftar & Detail Rekomendasi**: Menampilkan informasi lengkap tempat (foto, nama, lokasi, rating, estimasi biaya, deskripsi, hingga ulasan).
* **Indikator Pengembangan Fitur**: Notifikasi interaktif pada tombol *Add Review* untuk fitur ulasan yang akan segera hadir.

---

##  Kebutuhan Sistem
Agar aplikasi dapat berjalan dengan optimal, perangkat minimal harus memenuhi spesifikasi berikut:
* **Sistem Operasi**: Android 7.0 (Nougat) atau versi yang lebih baru.
* **RAM**: Minimal 2 GB.
* **Penyimpanan**: Ruang kosong minimal 100 MB.
* **Koneksi Internet**: Diperlukan untuk proses *Login* dan *Register* via Firebase.

---

##  Cara Instalasi Aplikasi
1. Salin file aplikasi (`FindSpotApp.apk`) ke perangkat Android Anda.
2. Buka aplikasi **File Manager** di perangkat.
3. Cari dan pilih file APK tersebut.
4. Tekan tombol **Install**.
5. Tunggu hingga proses instalasi selesai, lalu jalankan aplikasi melalui ikon **FindSpot**.
